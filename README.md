💪 AI Fitness Coach App
An AI-powered fitness assistant that generates personalized workout and diet plans using modern web technologies.

🚀 Live Demo
Frontend: http://localhost:3000

Backend API: http://localhost:5000

Health Check: http://localhost:5000/api/health

📋 Features
🎯 Core Features
Personalized Fitness Plans - AI-generated workout routines based on user profile

Custom Diet Plans - Meal plans tailored to dietary preferences

Voice Guidance - Text-to-speech for workout and diet plans

Image Generation - Visual representations of exercises and meals

PDF Export - Download your fitness plan as PDF

👤 User Profile Input
Personal details (Name, Age, Gender, Height, Weight)

Fitness goals (Weight Loss, Muscle Gain, Maintenance, etc.)

Fitness level (Beginner, Intermediate, Advanced)

Workout location (Home, Gym, Outdoor)

Dietary preferences (Veg, Non-Veg, Vegan, Keto)

Medical history and stress levels

🧠 AI-Powered Intelligence
Dynamic plan generation using AI models

Personalized recommendations

Motivational quotes and tips

Calorie calculations based on user metrics

🛠️ Tech Stack
Frontend
React.js - UI framework

Tailwind CSS - Styling

Framer Motion - Animations

Axios - API calls

html2canvas & jsPDF - PDF export

Backend
Node.js - Runtime environment

Express.js - Web framework

CORS - Cross-origin resource sharing

Axios - HTTP client

dotenv - Environment variables

AI Services
OpenAI GPT - Plan generation (configurable)

Web Speech API - Text-to-speech

Mock Data - Fallback for development
